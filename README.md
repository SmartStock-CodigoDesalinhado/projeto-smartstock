# 📦 SmartStock — Sistema Inteligente de Gerenciamento de Estoque

## 📌 Sobre o projeto

O **SmartStock** é um projeto de Trabalho de Conclusão de Curso (TCC) desenvolvido para facilitar e otimizar o gerenciamento de estoque de supermercados.

O sistema tem como objetivo oferecer uma plataforma moderna, intuitiva e eficiente para o controle de produtos, fornecedores, quantidades disponíveis e movimentações de estoque.

## 🚀 Funcionalidades

- Cadastro e gerenciamento de produtos.
- Cadastro e gerenciamento de fornecedores.
- Monitoramento e controle de estoque.
- Registro de entradas e saídas de produtos.
- Dashboard com indicadores e alertas de estoque.
- Autenticação e gerenciamento de usuários.

## 💻 Tecnologias utilizadas

- **Frontend:** HTML5, CSS3 e JavaScript.
- **Backend:** Java e Spring Boot.
- **Banco de dados:** MySQL.
- **Integração:** API REST.

## 🎯 Objetivo

Desenvolver uma solução que facilite a organização e o acompanhamento dos estoques de supermercados, contribuindo para a redução de perdas, a identificação de produtos que precisam de reposição e a melhoria da gestão operacional.
